## 🎯 নতুন ও আকর্ষণীয় সুবিধাসমূহ (New Features)

1. **পৃথক ইউজার আইডি ও প্রোফাইল সিস্টেম:**
   - যে কেউ তার ইউজার আইডি দিয়ে লগইন করলেই তার নাম ও রোল সিলেক্ট হয়ে যাবে।
   - লিংকে `?user=topu` বা `?user=tonmoy` লিখে পাঠালে প্রাপক সরাসরি তার আইডিতে লগইন হয়ে যাবে!

2. **ব্যক্তিগত আলাদা ড্যাশবোর্ড (Personal Isolated Dashboard):**
   - টপুর পরীক্ষায় টপুর প্রাপ্ত নম্বর ও পরীক্ষার ইতিহাস জমা থাকবে।
   - তন্ময় বা মালিহার পরীক্ষায় তাদের নিজস্ব পরীক্ষার ক্রমিক নম্বর (#1, #2...), তারিখ, সময় ও স্কোর আলাদাভাবে জমা থাকবে।
   - একজনের ইতিহাস মুছে ফেললে অন্য কারো ইতিহাস কখনোই মুছবে না।

3. **পারিবারিক লিডারবোর্ড (Family Ranking & Leaderboard):**
   - ড্যাশবোর্ডের ২য় ট্যাবে পুরো পরিবারের সকলের স্কোর ও র‍্যাংকিং এক নজরে দেখা যাবে! কার স্কোর সবচেয়ে বেশি (🥇 ১ম, 🥈 ২য়, 🥉 ৩য়), কে কতটি পরীক্ষা দিয়েছে তা দেখা যাবে।

4. **স্তরভিত্তিক প্রশ্ন নির্বাচন (Target Level Selection):**
   - **Class 2 - 4 (Primary School):** ছোটদের উপযোগী সহজ নিয়ম।
   - **SSC Exam (Board Standard):** মাধ্যমিক ও বোর্ড পরীক্ষার ট্রান্সফরমেশন নিয়ম।
   - **BCS & Job Exam (Advanced Standard):** বিসিএস, ব্যাংক ও বিশ্ববিদ্যালয় ভর্তি পরীক্ষার স্ট্যান্ডার্ড প্রশ্ন (*"What though..."*, *"Their glory can never fade"*, *"It is no use crying over spilt milk"*, ইত্যাদি)।
   - **All Combined:** সকল স্তরের প্রশ্ন মিলিয়ে পরীক্ষা দেওয়ার সুবিধা।

5. **পরীক্ষার অপশন ও টাইমার:**
   - ১০, ২০, ৫০ ও ১০০টি প্রশ্ন নির্বাচনের সুবিধা।
   - স্বাভাবিক সময়, স্পিড টেস্ট এবং সময়সীমা ছাড়া অনুশীলন মোড।
   - পরীক্ষা শেষে বিস্তারিত উত্তর পর্যালোচনা ও ব্যাকরণ টিপস (Grammar Tips)।

## 🚀 গিটহাবে আপডেট পুশ করার নিয়ম (Update Live Site)

আপনি যেহেতু ইতিমধ্যে গিটহাবে আপলোড করেছেন, নতুন ফাইলগুলো আপডেট করতে:

### উপায় ১: GitHub ওয়েবসাইটে সরাসরি ফাইল রিপ্লেস
1. আপনার GitHub রিপোজিটোরিতে যান (`mugdho-exam`)।
2. **"Add file" ➔ "Upload files"**-এ ক্লিক করুন।
3. আপনার ফোল্ডারের ফাইলগুলো (`index.html`, `style.css`, `questions.js`, `app.js`, `README.md`) ড্র্যাগ করে দিন।
4. নিচে **"Commit changes"** বাটনে ক্লিক করুন।
5. ১ মিনিটের মধ্যে লাইভ সাইট আপডেট হয়ে যাবে!

### উপায় ২: Git কমান্ড লাইন দিয়ে (যদি গিট সেটআপ থাকে)
```bash
git add .
git commit -m "Add multi-user system for Topu, Tonmoy, Maliha and Mugdho"
git push origin main
```
